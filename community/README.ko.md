# 커뮤니티 캐릭터는 옮겼어요

커뮤니티 캐릭터는 이제 **[dot-buddy/characters](https://github.com/dot-buddy/characters/blob/main/README.ko.md)** 에 있어요. [갤러리](https://dot-buddy.github.io/characters/ko/)에서 둘러보고 zip 을 받아 펫에 끌어다 놓을 수 있어요.

- 캐릭터를 올리려면 그 레포에 풀 리퀘스트를 열어 주세요.
- 신고는 [그 레포의 이슈](https://github.com/dot-buddy/characters/issues/new/choose)로 해 주세요.

이 폴더의 꾸러미는 0.3.17 전 버전 앱이 여기서 `community/index.json` 을 읽기 때문에 남겨 둔 고정본이에요. 더는 고치지 않아요.
